# Technical project brief

Scientific measurements can remain in an HDF5 file after damage to the metadata used to locate chunked dataset data. H5Reclaim investigates whether it can recover some of those bytes at justified coordinates and expose uncertainty clearly.

The first supported case was a fixed, unfiltered rank-two canonical uint32 dataset with one broken root-to-leaf pointer in an older version-1 B-tree. The controlled GWOSC 16 kHz strain trial exercised rank-one float64 with Fletcher32 followed by DEFLATE and recovered 57 native-inaccessible chunks through one uniquely bridged leaf. Those early cases are retained as regression baselines.

The chunked structural route supports bounded rank-one through rank-four canonical fixed-width integer and IEEE float storage, either byte order, with partial edge chunks, sparse unknown cells, growth and built-in shuffle, DEFLATE and Fletcher32 in actual file order. Older B-trees can bridge one leaf only with two reciprocal sibling anchors and matching parent interval. Five modern chunk-index families have intact-index parsers, including filtered/paged fixed and extensible arrays and version-2 B-tree. One missing fixed-array header to data-block pointer has a narrow reconstruction when a unique candidate restores the original checked header, has a checked back-pointer, and passes coordinate and range validation; other missing modern links remain unsupported. A rooted raw metadata fallback can resolve selected older or modern local hard-link paths after some native metadata-open failures, including bounded selected SOHM B-tree shared messages. Its older graph has no link checksums. A separate rooted compact/contiguous route can locate complete numeric elements, including surviving prefixes after physical truncation.

The guided command can also materialize bounded values from explicit hash-pinned external raw files, finite virtual-dataset sources, one pinned external-link HDF5 target, Family or two-member Split driver files, or matching independently parsed replicas with a separately captured prior chunk-hash baseline. A checked version-3 status-only trial can change flag and checksum in a disposable copy before bounded native-readable export. Prior element or chunk hashes can withhold current payloads that differ from independently retained capture evidence; they do not reconstruct lost values. A bounded child copies currently readable fixed-size local datasets, including some filters and references, without claiming damaged-index repair. These routes retain selected schema and validity while recording when a derived output changes the original external/virtual storage layout. A matching current-file hash does not prove scientific history; the prospective baseline must be kept independently and cannot be created after the original capture has vanished.

The implementation reads the source without modifying it and analyzes a private snapshot so native metadata access and raw parsers see the same bytes. Accepted chunks need a selected dataset anchor, justified coordinate and physical extent, nonoverlap, bounded filter reversal, and explicit integrity status. The output carries a chunk validity map and an evidence ledger; neither an unfiltered payload nor a successful HDF5 read proves its historical value. Ground truth is used only by controlled evaluators. Links, sibling objects, dimension scales and full scientific context are not reproduced.

Four unchanged scientific files are bundled with provenance and pinned hashes. Six of 251 local datasets pass chunked metadata/index preflight, and an independent intact-file evaluator checked 196/196 accepted chunks against the originals. Two structurally unsupported Zenodo representatives were exported through the native-readable route and independently compared. The controlled 16 kHz GWOSC broken-pointer case remains one specific repair demonstration; a separate controlled metadata fault exercises older rooted fallback. Generated modern-link and shared-message fixtures cover additional format gates. A stratified constructed matrix includes safe refusals and deliberate unchecksummed wrong-value acceptance. The new separately supplied panel runner measures explicit denominators, exclusions, exact/wrong values, and refusals by fault family. No representative naturally damaged multi-lab panel has been scored, so none of these tests estimates a real-world recovery percentage. The current support details and limits are in [status](status.md), [usage](usage.md), and [damage taxonomy](damage-taxonomy.md).

Potential users include researchers and research software engineers handling interrupted workflows. Recovery has been demonstrated on one controlled failure in authentic scientific data and on a synthetic fixture. A naturally corrupted scientific file, comparative advantage, independent use, production reliability, and publication have not been established.

Technical format reference: [HDF5 File Format Specification, Version 4.0](https://support.hdfgroup.org/documentation/hdf5/latest/_f_m_t4.html).
