# Technical project brief

Scientific measurements can remain in an HDF5 file after damage to the metadata used to locate chunked dataset data. H5Reclaim investigates whether it can recover some of those bytes at justified coordinates and expose uncertainty clearly.

The first supported case was a fixed, unfiltered rank-two canonical uint32 dataset with one broken root-to-leaf pointer in an older version-1 B-tree. The controlled GWOSC 16 kHz strain trial exercised rank-one float64 with Fletcher32 followed by DEFLATE and recovered 57 native-inaccessible chunks through one uniquely bridged leaf. Those early cases are retained as regression baselines.

The chunked structural route supports bounded rank-one through rank-four canonical fixed-width numeric storage and selected self-contained compound, enum, array, fixed-string and opaque records. It handles partial edge chunks, sparse unknown cells, growth and built-in shuffle, DEFLATE and Fletcher32 in declared order. Older B-trees can bridge one leaf or internal subtree only with reciprocal rooted neighboring anchors, matching parent interval and a complete disjoint candidate. Five modern chunk-index families have bounded intact parsers, with selected one-link repairs when a unique substitution restores the original parent checksum and child, coordinate, range and ownership checks agree. Other lost modern links refuse. A rooted raw metadata fallback can resolve selected older or modern local hard-link paths after some native metadata-open failures, including bounded selected SOHM B-tree shared messages. Its older graph has no link checksums. A separate rooted compact/contiguous route can locate complete numeric elements, including surviving prefixes after physical truncation.

The guided command can also materialize bounded values from explicit hash-pinned external raw files, finite virtual-dataset sources including one pinned nested VDS hop, one external-link HDF5 target, Family or two-member Split files, or matching independently parsed replicas with a separately captured prior chunk baseline. A checked version-3 status trial changes flag and checksum only in a disposable copy before bounded native-readable export. Prospective element/chunk hashes can withhold changed values; a schema/physical capsule can retain surviving bytes after root loss; and multiple parity shards can reconstruct selected losses. `protect` captures and drills a pinned bundle of those prospective components. The `--strict-history` gate refuses an unprotected export and reports equality to an operator-supplied prior capture separately from current structural validity. A bounded child copies currently readable fixed-size local datasets, including some filters and references, without claiming damaged-index repair. A matching hash does not authenticate capture time or scientific correctness.

The implementation reads the source without modifying it and analyzes a private snapshot so native metadata access and raw parsers see the same bytes. Accepted chunks need a selected dataset anchor or independently retained capsule, justified coordinate and physical extent, nonoverlap, bounded filter reversal, and explicit integrity status. The output carries a validity map, a historical-status map when bounded, and an evidence report; neither an unfiltered payload nor a successful HDF5 read proves its historical value. Ground truth is used only by separate evaluators. A bounded context audit names scientific metadata omitted from the derived output; links, sibling objects and dimension-scale targets are not reproduced.

Four unchanged scientific files are bundled with provenance and pinned hashes. Six of 251 local datasets pass chunked metadata/index preflight, and an independent intact-file evaluator checked 196/196 accepted chunks against the originals. Two structurally unsupported Zenodo representatives were exported through the native-readable route and independently compared. The controlled 16 kHz GWOSC broken-pointer case remains one specific repair demonstration; a separate controlled metadata fault exercises older rooted fallback. Generated modern-link and shared-message fixtures cover additional format gates. A stratified constructed matrix includes safe refusals and deliberate unchecksummed wrong-value acceptance. The new separately supplied panel runner measures explicit denominators, exclusions, exact/wrong values, and refusals by fault family. No representative naturally damaged multi-lab panel has been scored, so none of these tests estimates a real-world recovery percentage. The current support details and limits are in [status](status.md), [usage](usage.md), and [damage taxonomy](damage-taxonomy.md).

Potential users include researchers and research software engineers handling interrupted workflows. Several selected controlled failures in authentic scientific copies and generated fixtures have been checked against separate truth. The incident intake runner is ready for permissioned natural cases, but none has been scored with an independent historical reference. Comparative advantage, independent use, production reliability, and a representative field recovery rate have not been established.

Technical format reference: [HDF5 File Format Specification, Version 4.0](https://support.hdfgroup.org/documentation/hdf5/latest/_f_m_t4.html).
