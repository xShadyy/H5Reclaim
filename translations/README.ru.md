H5Reclaim восстанавливает научные данные из повреждённых файлов HDF5. После прерванной записи, нарушения индексов, повреждения метаданных или усечения файла программа переносит уцелевшие измерения в новый пригодный для работы файл. Формат HDF5 используется многими научными приборами и приложениями для хранения массивов, измерений и их метаданных.

**Одна команда находит наборы данных, выбирает способы восстановления и создаёт новый файл HDF5 с понятным отчётом в формате JSON.** Исходный файл остаётся неизменным. H5Reclaim сохраняет читаемые измерения из частично повреждённых наборов данных и продолжает восстанавливать остальную часть файла.

Версия 1.0.0 обеспечила **полезное восстановление в 95,4% из 109 контролируемых испытаний с повреждёнными файлами**: 77 полностью точных и 27 частичных восстановлений без ошибочно принятых значений в этой серии испытаний. Эти сгенерированные испытания проверяют заявленные классы повреждений, а не ожидаемую вероятность успеха для других файлов. [Изучить результаты](https://github.com/xShadyy/H5Reclaim/blob/main/benchmarks/results/v100rc1-release-coverage.json).

Инструменты проверки и исправления, поддерживаемые форматы, проверка результатов и пакетная обработка описаны в [руководстве](../USAGE.md).

## Начало работы

Требуется Python 3.10 или новее. Клонируйте репозиторий либо скачайте и распакуйте его ZIP-архив с GitHub:

```sh
git clone https://github.com/xShadyy/H5Reclaim.git
cd H5Reclaim
```

Установите программу из корневого каталога репозитория и восстановите файл:

```sh
python -m pip install .
python -m h5reclaim rescue "damaged.h5"
```

## Как понимать результат

Сводка в терминале показывает, было ли восстановление полным или частичным, и указывает расположение выходных файлов. В отчёте JSON перечислены восстановленные наборы данных, применённые методы, неразрешённые позиции и восстановленные метаданные.

Если метод создаёт **карту состояний**, она показывает позиции, содержащие принятые измерения. Для анализа выбирайте значения по карте, указанной в отчёте; неизвестные позиции могут отображаться как заполнитель, например ноль. Для некоторых неповреждённых непрерывных наборов данных и наборов данных типа null проверяемая карта отсутствует, поэтому перед анализом ознакомьтесь с отчётом для соответствующего метода. Ранее сохранённые базовые копии и комплекты защиты позволяют сопоставить результат с более ранним снимком данных.
